El código simula el funcionamiento de un semáforo utilizando un Arduino. Tiene tres LEDs: rojo, amarillo y verde, que se encienden de manera ordenada para representar las señales de tránsito. El LED rojo permanece encendido durante 5 segundos, el verde durante 5 segundos y el amarillo durante 2 segundos. Luego, el ciclo vuelve a comenzar automáticamente gracias a la función `loop()`.
